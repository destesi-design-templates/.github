# Destesi Design templates

Starting designs for [Destesi Design](https://destesi.io). Each repository is
one template — its pages, its look, its demo and the skills the Design agent
reads in a project started from it. Shop templates (`backend: commerce`) sell
through Destesi Commerce, with catalog and stock from Destesi Inventory.

How a template is built, what it may not change and how a change reaches
merchants: [TEMPLATES.md](https://github.com/destesi-design-templates/.github/blob/main/TEMPLATES.md).
